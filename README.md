# ポケスリ 厳選診断

（フォルダ名／リポジトリ名：**`pksl.gensen-shindan`**　すべて小文字です）

ポケモンスリープで「欲しいサブスキル・せいかく・食材」を入力すると、
**その個体はたぶん何体目で出るのか**（50%・80%・90%・99%ライン）を計算する一枚ページ。
**銀種（サブスキルのたね）で格上げすれば条件を満たせる個体も"当たり"に数えられる**のが特徴です。

同じ `ポケスリ` フォルダにある **`pksl.snacktimesim`（おやつタイムシミュレーター）** の
ポケモンデータとサブスキルの確率をそのまま使っています。あちらは「引いて眺める」ツール、
こちらは「確率を計算する」ツールです。

## 開きかた

このフォルダの **`サイトを開く.bat`** をダブルクリックしてください。
うまくいかないときは、同じフォルダの `index.html` を右クリック →
「プログラムから開く」→ Chrome や Edge を選んでも同じことができます。

インストール作業もサーバーも不要です。インターネットが無くても動きます
（文字のデザインだけ標準のものになります）。入力した内容はブラウザの中に保存され、
次に開いたときも残っています。

## 使いかた

1. **① どのポケモン？** … 名前で検索して選びます。**食材の並びを見るときだけ**使います
   （サブスキルとせいかくの確率はどのポケモンでも同じです）。
2. **② 金枠確定（フレンドメダル）** … なし／1つ／2つ／3つ。上の枠から順に金が確定します。
3. **③ 欲しいサブスキル** … ボタンを押すと、下に **条件の行** が1つ増えます（5行まで）。
   **行はぜんぶ必要**（＝「＆」。順番は問いません）。
   - 行の中の **「＋ または…」** から足すと、その行は **「このうちどれかでよい」**（＝「または」）になります。
     例：「きのみの数S または おてつだいボーナス」
   - 2つ以上入った行には **「このうち ○つ以上」** が出ます。「3つのうち2つ以上」のような指定もできます。
   - 行ごとに「この枠までに」を変えられます。例：「きのみの数S は Lv25 まで」
4. **④ 銀種を何個まで使う？** … 使わない／1個まで／2個まで／3個まで。
5. **⑤ せいかく** … 上がってほしい補正を1つ選び、下がったらイヤな補正にチェック。
   「当たりのせいかく：○種／25種」と出ます。こだわらなければそのままで。
6. **⑥ 食材の並び** … AAA・AAB・ABB・ABC などを選びます。こだわらなければそのままで。
7. **診断結果** に、次が出ます。
   - **「たぶん ○体目で出る」** … 50%の人はここまでに1体は引けている、という数
   - **1体あたりの当たり確率**、**80%／90%／99%ライン**
   - **銀種なしだと ○体目** … 銀種で何倍出やすくなるか
   - **表** … 行＝銀種の個数、列＝サブスキルを何枠まで見るか（2枠＝Lv25まで、3枠＝Lv50まで、
     4枠＝Lv75まで、5枠＝Lv100まで）。中の数字は **80%ライン** と 1体あたりの確率。
     「サブスキルを何枠まで見る？」のチップで、大きく表示する列を切り替えられます。

## 計算のしかた・前提

- **サブスキルの出現率**：1枠あたり 金2%×7種・青6%×6種・白12.5%×4種。
  同じものが重ならないように、上の枠から順に引くものとして計算しています。
  出典：[ポケモンスリープ攻略・検証Wiki「サブスキル」](https://wikiwiki.jp/poke_sleep/%E3%82%B5%E3%83%96%E3%82%B9%E3%82%AD%E3%83%AB)
- **金枠確定**：確定した枠には金7種のどれかが同じ確率で入る、としています。
- **せいかく**：25種が同じ確率。
- **食材**：2枠目 A=1/3・B=2/3。3枠目は候補3種なら1/3ずつ、候補2種なら A=1/3・B=2/3。
- **○%ライン**：1体あたりの当たり確率を p として、「n体までに1体は出ている確率」が
  ○%を超える最小の n。式は n = ⌈log(1−○%) ÷ log(1−p)⌉ です。
- サブスキル5枠の並び（17×16×15×14×13 ≒ 74万通り）を**確率つきで全部たどって**足しているので、
  サイコロは振っていません。**同じ入力なら毎回同じ数字**が出ます。
  [Wikiの「厳選」ページ](https://wikiwiki.jp/poke_sleep/%E5%8E%B3%E9%81%B8)の数字
  （きのみの数S が Lv50までに出る確率 6.0%、きのみS＋おてボ 0.24%）と
  ほぼ一致すること（6.5%、0.27%）を確認しています。

### 銀種（サブスキルのたね）の扱い

調べた仕様（[Game8](https://game8.jp/pokemonsleep/542174)、
[ちゃむのポケモン部屋](https://ameblo.jp/charmingp0kem0nr00m/entry-12877205271.html)、
[おろぶろぐ](https://www.orooroktgameblog.net/entry/2024/10/21/071707)）をもとに、
次のルールで計算しています。

- 銀種は「**そのとき解放されている枠**のうち、ランクを上げられるものを **1つランダムに** 上げる」。
- 上げられるのは次の6つだけ。金や、M が最高ランクのものは上がりません。
  - おてつだいスピードS → M　／　食材確率アップS → M　／　スキル確率アップS → M
  - 最大所持数アップS → M　／　最大所持数アップM → L
  - **スキルレベルアップS → M（金になる）**
- 同じサブスキルは1匹に2つ持てないので、上げた結果が既に持っているものと重なる枠は対象外。
- **使うレベルは自分で選べる**（Lv25になる前に使えば1枠目に確定、など）ものとして、
  いちばん成功しやすいタイミングで使った場合の確率を出しています。
  対象が複数あるときは、どれが上がるかは同じ確率です。

> ⚠ **1匹に何個まで使えるか**は、どの記事にも明記がありませんでした。
> このツールでは個数を選べるようにしてあります。「1匹1回まで」だと分かったら
> 「1個まで」を選んでください。

## このフォルダにある `rironchi` の画像について

`ポケスリ/rironchi/furin1〜3.jpg` は、参考にした「必要捕獲数（80%ライン）」の表です。
**このツールの数字はその表と一致しません。** 同じ金サブスキルなのに
「きのみS＝15」「スキM＝9」と違う数字になっているなど、表のほうに別の前提が混ざっているようで、
再現できませんでした。このツールは上に書いた Wiki の前提にそろえてあります。

## 中身を直したくなったら

`index.html` をメモ帳（または VS Code）で開くと、`<script>` のすぐ下に
**「1. データ」** として表がまとまっています。

- `MON_DATA` … ポケモン245匹のデータ（自動生成した1行なので、ふだんは触りません）
- `SUBS` … サブスキル17種。`w:` が出る確率、`up:` が銀種で格上げした先の番号（無ければ -1）
- `LV_SUB` … 枠が開くレベルの表示
- `NAT_RAW` … せいかく25種
